# 仓储管理系统
## 项目简介
本系统采用 Java Swing + MySQL 开发，是一套进销存仓储管理程序。系统实现进货、销售、库存盘点、库存统计、数据库备份恢复等核心功能，同时实现供应商、客户信息管理。

## 技术要点
- 前端界面：Java Swing
- 数据库：MySQL 8.0
- 数据库连接：JDBC
- 特色：事件监听、数据库可视化备份与恢复

## 功能列表
### 基础功能
1.  **进货单管理**：录入供应商ID、商品ID、进货数量、进货单价，提交后自动计算总价并更新库存。
2.  **销售单管理**：录入客户ID、商品ID、销售数量、销售单价，保存后自动核算销售金额、扣减库存。
3.  **库存盘点**：查看商品编号、名称、系统库存，录入实际盘点数量，自动计算盘盈盘亏，支持保存盘点结果、更新库存。
4.  **库存统计**：统计本月进货总量、销售总量，直观展示周期进销数据。
5.  **数据库备份与恢复**：可视化操作界面，支持一键备份数据库到指定路径，也可以从备份文件恢复，备份过程带有进度条与完成提示。
6.  **库存事件监听**：进货或销售造成库存变动后，库存列表自动刷新，不需要手动刷新页面。

### 扩展加分功能
- 供应商信息管理
- 客户信息管理

## 运行说明
1.  环境：JDK1.8 及以上，MySQL8.0
2.  先执行数据库SQL脚本，创建数据表
3.  修改JDBC连接配置，填写自己MySQL的账号和密码
4.  运行 `MainFrame` 类，启动系统主界面
